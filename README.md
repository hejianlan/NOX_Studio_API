# NOX Studio

NOX Studio 是一套面向 AI 创作平台运营方的商业化系统，覆盖用户注册、积分计费、模型渠道管理、AI 图片/视频创作、无限画布、素材资产、后台运营、日志审计、告警通知与部署授权等完整链路。

本仓库仅用于对外展示项目介绍、功能清单与授权合作信息，不包含产品源代码。如需部署、二次开发或商业授权，请通过文末联系方式咨询。

## 产品定位

NOX Studio 适合想快速搭建自有 AI 创作平台、AI 工具站、AI 图片/视频生成站、模型中转服务或会员积分制 SaaS 的团队。

系统采用“创作应用层 + 基础能力层”的双层架构：上层可以持续扩展文生图、图生图、文生视频、剧本创作、分镜提示词、视频翻译等创作应用；底层统一处理模型规格、渠道调度、积分预扣、失败退款、日志审计和后台配置。

## 核心卖点

- 完整商业闭环：账号、积分、充值、兑换码、订单、账单、邀请返利、活动运营一体化。
- 多渠道模型网关：支持多个上游渠道、模型映射、优先级、权重、失败重试、熔断与健康监控。
- 用户无感知调度：前台只展示产品规格和价格，不暴露渠道、上游模型和原始错误。
- AI 创作工作台：支持图片生成、图片编辑、视频生成、任务队列、生成历史与结果资产化。
- 无限画布能力：支持节点、连线、项目保存、素材引用和工作流式创作。
- 管理后台完善：用户、渠道、模型、定价、订单、兑换码、日志、告警、系统设置集中管理。
- 可授权交付：适合私有化部署、品牌定制、二开交付和运营平台授权销售。

## 授权合作

本项目支持以下合作形式：

- 商业授权：购买授权后用于自有品牌运营。
- 私有化部署：部署到客户自有服务器或云环境。
- 品牌定制：支持站点名称、Logo、主题、菜单、定价与文案定制。
- 二次开发：按业务需求增加创作应用、支付渠道、模型渠道或运营模块。
- 源码授权：按授权级别协商，默认展示仓库不包含源码。
